# E-commerce ядро с абстрактным классом и миксином

## Реализовано в домашнем задании 16.2

### Абстрактный класс BaseProduct
- Базовый класс для всех продуктов
- Содержит абстрактные методы: __str__, __add__, price

### Миксин LogMixin
- Логирует создание объектов
- Выводит информацию о классе и параметрах

### Классы-наследники
- Product (базовый продукт)
- Smartphone (смартфон)
- LawnGrass (газонная трава)
